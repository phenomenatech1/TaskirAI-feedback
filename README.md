# TaskirAI Feedback & Issue Tracker

Welcome to the public issue tracker for **TaskirAI**! 

Use this repository to submit bug reports, suggest feature enhancements, or ask general questions about TaskirAI.

---

## 📌 How to Submit an Issue

Before creating a new issue, please check the [existing issues](https://github.com/phenomenatech1/TaskirAI-feedback/issues) to make sure your topic hasn't already been reported or discussed.

### 🐛 Reporting a Bug
When filing a bug report, please include:
- A clear, descriptive title.
- Steps to reproduce the behavior.
- Expected behavior vs. actual behavior.
- Relevant screenshots or screen recordings (if applicable).
- Device, browser, and OS specifications.

### 💡 Requesting a Feature
When proposing a feature or improvement:
- Describe the problem or workflow bottleneck you are experiencing.
- Explain your proposed solution or idea.
- Provide any mockups, examples, or alternative solutions you've considered.

---

## 🔒 Security Vulnerabilities

Please **do not** open public issues for security bugs, sensitive data exposures, or credential leaks.

If you discover a security vulnerability, report it privately by emailing us directly or contacting the team via official channels.

---

## 🤝 Community Guidelines

Please keep all interactions respectful, constructive, and aligned with community standards.
